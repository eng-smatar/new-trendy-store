# Shipping Address Structure and Data

Everything needed to reproduce the delivery address form and shipping fee calculation on another website.

- Hierarchy: **District → City → free-text address**. There is no country or postal code field.
- 18 districts, 576 cities. Names are in Arabic.
- Currency: ILS (₪).
- Estimated delivery: 2–5 days.
- Payment: cash on delivery.

## 1. Address form fields

| Field | Label (EN / AR) | Input | Rules |
|---|---|---|---|
| `first_name` | First name | text | required, max 100 |
| `last_name` | Last name | text | required, max 100 |
| `phone` | Phone | tel (LTR) | required, max 40 |
| `email` | Email | email (LTR) | optional, valid email, max 255 |
| `gender` | Gender | radio | required, `male` or `female` |
| `district_id` | District / المحافظة | select | required, must be a district `id` |
| `city_id` | City / المدينة | select | required, must be a city `id` inside the selected district |
| `address_line1` | Address / العنوان | text | required, max 255 |
| `notes` | Order notes | textarea | optional, max 1000 |

Behaviour:

- The city select is disabled until a district is chosen ("Select a district first" / اختر المحافظة أولاً).
- Changing the district clears the selected city.
- Placeholders: "Select a district" / اختر المحافظة, "Select a city" / اختر المدينة.
- The shipping fee updates as soon as the district changes.

## 2. What is stored on an order

The order keeps the district and city **names** as a snapshot, not their ids.

| Column | Type |
|---|---|
| `first_name`, `last_name` | string |
| `phone` | string(40) |
| `email` | string, nullable |
| `gender` | string(10) |
| `district` | string (district name) |
| `city` | string (city name) |
| `address_line1` | string |
| `notes` | text, nullable |
| `shipping_total` | decimal(10,2) |

Full address display: `address_line1, city, district` (empty parts skipped).

## 3. Shipping fees

Each district has a `zone`. The zone sets the fee.

### Rates are managed from the admin

The shipping fee and free-shipping threshold are **not hardcoded**. An admin edits them on the **Shipping** page of the admin panel, and the other website should do the same.

- Stored in the `shipping_zones` table, one row per zone: `zone_key` (unique string), `fee` decimal(10,2), `free_from` decimal(10,2).
- The admin can edit `fee` and `free_from` for each zone. Both are required numbers, minimum 0.
- The admin page does not add, remove or rename zones.
- Checkout reads the current values from the database, so a saved change applies without a deployment.
- Each order saves its own `shipping_total`, so later rate changes do not alter existing orders.

The values below are the rates at the time of writing. Use them as initial seed data only.

| Zone key | Label (EN / AR) | Fee (₪) | Free when subtotal ≥ (₪) | Districts |
|---|---|---|---|---|
| `Isreal` | Israel / الداخل | 65 | 1000 | ids 256–262 |
| `Jerusalem` | Jerusalem / القدس | 30 | 500 | id 248 |
| `default` | Other districts / باقي المحافظات | 20 | 250 | all others |

```js
function shippingFee(district, subtotal, rates) {
  const rule = rates[district?.zone] ?? rates.default;
  return subtotal >= rule.free_from ? 0 : rule.fee;
}
```

Notes:

- `Isreal` is misspelled in the source data. It is a lookup key, so keep it identical in both places (or rename it in both).
- West Bank districts carry `zone: "Asia"`. There is no `Asia` rate, so they use `default`.
- These values were read from the local database on 2026-11-25; confirm them against production.

```json
{
  "Isreal":    { "fee": 65, "free_from": 1000 },
  "Jerusalem": { "fee": 30, "free_from": 500 },
  "default":   { "fee": 20, "free_from": 250 }
}
```
